# v 0.0.1

Небольшая авторегрессионная языковая модель на PyTorch и Transformer.

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Поместить текст в `data/train.txt` (UTF-8).
3. Обучить: `python train.py`
4. Генерировать текст: `python generate.py`

Первая версия использует символьную токенизацию. Это стартовая ступень проекта, а не готовый чат-бот.
